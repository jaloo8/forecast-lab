[144–185](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/graph/setup.py#L144-L185) fans analysts and memory out, joins their results, then runs bull/bear debate, research manager, trader, risk debate, and portfolio manager before ending. Analyst parallelism is real in this revision; the entire workflow is not parallel. [conditional_logic.py:12–33](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/graph/conditional_logic.py#L12-L33) bounds debate turns.
- **Tool dates come from graph state.** [agents/tools.py](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/tools.py#L18-L38) injects the analyzed symbol/date and clamps requests through [date_window.py:78–105](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/date_window.py#L78-L105). Missing historical profiles, undated statements and undisclosed insider trades are explicitly withheld in shared guards (108–170). This is stronger than only telling an LLM to avoid future information.
- **Publication vintage is considered.** [sec_edgar.py:153–187](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/sec_edgar.py#L153-L187) selects the latest fact filed by the analysis date, distinguishes quarter/year-to-date periods and preserves units. [fred.py:192–235](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/fred.py#L192-L235) sends matching real-time vintage bounds with metadata and observations.
- **Memory checks when an outcome became known.** [memory/log.py:93–130](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/memory/log.py#L93-L130) excludes unresolved or later-resolved lessons from historical context. [settlement.py:52–103](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/memory/settlement.py#L52-L103) begins scoring at the first close after the analysis date, requires the complete holding window, and records its exit date. This avoids crediting a same-day close after reading that day's later news. It remains a date-level evaluation, not an intraday trading clock.
- **Missing portfolio context is not silently treated as zero holdings.** [portfolio.py:23–64](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/portfolio.py#L23-L64) accepts an optional book and fingerprints it for graph resumption; [agents/context.py:204–218](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/context.py#L204-L218) explicitly says when holdings/cash were not supplied.

## Concrete blockers and limits

1. **Recommendation evaluation is not account simulation.** [backtest.py:9–14](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/backtest.py#L9-L14) explicitly states there is no quantity, fill price or cash ledger; cells are independent and an optional supplied portfolio is reused unchanged. [184–214](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/backtest.py#L184-L214) reports rating hit rates and mean benchmark alpha, not NAV, annual return or drawdown. Settlement computes raw asset return minus benchmark return without execution costs. The graph finishes by saving a decision and returning a rating ([trading_graph.py:358–404](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/graph/trading_graph.py#L358-L404)). README line 109's simulated-exchange execution sentence is not established by this reviewed implementation. Forecast Lab still needs its funded-account, costs, integer sizing, cash/collateral, marks and lifecycle accounting.

2. **Date filters are not a complete historical dataset.** The default indicator loader downloads only the latest five years relative to the current computer date and then filters to the historical decision date ([yahoo/ohlcv.py:161–188,212–230](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/yahoo/ohlcv.py#L161-L230)). This path cannot supply a 2000/2006-start feature history as written. It fetches current auto-adjusted prices; absolute historical entry/stop levels need a separate corporate-action/vintage contract. Yahoo news and public social feeds retrieve recent items, filter timestamps, and report unavailable windows; they do not restore old archives ([yahoo/news.py:87–134](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/yahoo/news.py#L87-L134), [stocktwits.py:74–120](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/stocktwits.py#L74-L120)). The sentiment module itself states the historical inputs are not point-in-time (lines 10–13). Current SEC ticker mapping ([sec_edgar.py:135–142](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/sec_edgar.py#L135-L142)) and current company names in historical prompts ([context.py:120–143](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/context.py#L120-L143)) do not provide a historical security master or delisted-inclusive universe. Today's pretrained model knowledge is an additional unmeasured hindsight channel.

3. **A reused backtest ID can mix experiment settings.** Static code path: [backtest.py:148–177](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/backtest.py#L148-L177) opens an existing run's memory log and skips cells based only on ticker/date; there is no run-configuration fingerprint check in this function. Reusing the ID after changing model, analysts, supplied book or holding period can retain older cells and execute/settle remaining cells under new settings. The separate graph checkpoint signature is useful but does not guard this completed-cell skip. Require immutable preregistration/config/input hashes per experiment and reject mismatched resumes. This was identified by static inspection, not exercised.

4. **Structured prose is not a validated executable order.** Trader sizing is optional free text and prices have no positive/finite constraint in the reviewed schema ([schemas.py:146–188](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/schemas.py#L146-L188)). Any structured invocation failure can trigger a second plain-text call ([structured.py:59–95](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/structured.py#L59-L95)); the portfolio manager can accept a rating parsed from that fallback. Useful for displaying research, insufficient for order submission. Require a deterministic, fail-closed downstream schema/account gate rather than feeding these strings to a broker.

5. **Hidden additional spending paths matter.** Merely setting `TYPESAFE_API_KEY` enables optional Jev screening ([post_screen.py:133–159](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/post_screen.py#L133-L159)). Each fetched social post can cause one POST, with 16 workers and up to 3 attempts/request; outstanding requests may finish after a failure ([31–34,68–98,167–181](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/post_screen.py#L167-L181)). Memory settlement also calls the LLM once per matured decision ([settlement.py:128–159](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/memory/settlement.py#L128-L159)). Root reviews primary-provider caps separately. These extra paths must share an actual reservation ledger, credential/endpoint allowlist and fail-closed budget. Current external allowance remains zero; no provider balance was inferred.

6. **External content reaches a high-trust prompt.** The sentiment analyst concatenates raw news/social text into the system message ([sentiment_analyst.py:88–112,147–170](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/analysts/sentiment_analyst.py#L88-L112)). Markers label sources but are not a security boundary. This node has no execution tools, limiting direct side effects, but hostile source text could still influence reports and downstream recommendations. Treat it as untrusted data, retain source receipts, and independently validate factual claims. No exploit was attempted or demonstrated.
