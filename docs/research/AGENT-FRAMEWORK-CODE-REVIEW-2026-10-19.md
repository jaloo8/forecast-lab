# TradingAgents and Vibe-Trading: source review for Forecast Lab

Reviewed October 19, 2026. This is a targeted static code/documentation review, not a whole-repository audit, installation, runtime benchmark or independent performance reproduction. No new strategy, model job or broker connection was activated. The objective remains 10–20% profit in every complete calendar year with a $1,000 practical reference.

## Decision

Use TradingAgents as the first reference for a bounded analyst/critic experiment. Use selected Vibe-Trading designs as engineering references. Retain Forecast Lab's deterministic experiments, account accounting and execution boundaries. Neither a collection of agent roles nor these repositories establishes the requested annual outcome.

This extends the [earlier paper review](AGENT-TRADING-SOURCE-REVIEW-2026-10-19.md) and [proposed process pilot](AGENT-RESEARCH-FLOOR-2026-10-19.md); it does not replace their registered limits. Current code is materially newer than the paper versions. Do not attribute current implementation features to the paper's original results.

## TradingAgents: useful analysis orchestration, incomplete account evaluation

**Direct:** independent analysts run concurrently, then join before bullish/bearish research, a research manager, trader, risk debate and portfolio-manager decision. Analyst tool loops are bounded. This is an implemented workflow, not just role names in the README. [Graph setup, lines 53–90 and 144–185](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/graph/setup.py#L53).

**Direct:** `backtest.py` expressly evaluates independent ticker/date decisions. It has no quantities, fill prices or cash ledger; an optional portfolio is the same standing book for every cell. Its summary reports rating hit rates and mean benchmark-relative returns. The graph returns a saved decision/rating. These are not funded-account CAGR or annual returns, despite the README's simulated-exchange description. [Evaluation scope, lines 1–14](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/backtest.py#L1), [summary, lines 184–214](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/backtest.py#L184), [graph output, lines 358–404](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/graph/trading_graph.py#L358).

**Direct:** SEC financial facts are selected by filing availability, a useful defense against using later disclosures. The company lookup still uses a current ticker map. The Yahoo indicator loader downloads approximately five years relative to today's date before filtering to the requested historical date, and uses currently adjusted prices. This path is not a 2000/2006-start feature archive or point-in-time stock universe. Current identity metadata can reach historical prompts with a current-data label. [SEC facts, lines 135–187](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/sec_edgar.py#L135), [Yahoo indicators, lines 161–230](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/dataflows/vendors/yahoo/ohlcv.py#L161), [context, lines 120–143](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/context.py#L120).

**Inference:** borrow the explicit dependency graph, bounded critique and structured decision contracts. Supply our own frozen, timestamp-qualified evidence and isolated memory. A historical date in a prompt does not remove future knowledge from model weights. Adjusted-price features and executable historical price levels require separate corporate-action assumptions. Do not translate recommendation hit rates into a $1,000 portfolio result.

**Direct:** current code also clamps tool dates to the graph's analysis date, excludes later-resolved memories from historical context and begins outcome scoring at the first close after the analysis date. These are concrete safeguards worth preserving. They do not create missing historical archives or erase model pretraining knowledge. [Tool dates](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/tools.py#L18), [historical memory](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/memory/log.py#L93), [outcome timing](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/memory/settlement.py#L52).

**Direct / code-path inference:** the batch backtest skips completed cells by ticker/date when a run ID is reused, without checking a fingerprint of its model, analyst, supplied-book and holding-period settings in that function. A changed configuration can therefore mix old cells with newly generated/settled cells. Require immutable experiment manifests and reject mismatched resumes. This was identified statically, not exercised. [Batch resume, lines 148–177](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/backtest.py#L148).

**Direct:** default output-token and retry settings defer to providers, while debate/tool-round limits constrain the graph. The reviewed configuration/client path has no aggregate dollar reservation across calls. Social-post screening has a separate request path enabled by a configured TypeSafe key; structured-output fallback and memory reflections can add calls. [Defaults, lines 109–137](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/default_config.py#L109), [provider options, lines 94–134](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/llm_clients/factory.py#L94), [screening](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/agents/post_screen.py#L133).

**Inference:** a pilot adapter must count all model/tool paths, retries and reflections under one shared allowance. Limit each response and reserve its worst-case cost before submission. A finite debate count alone is not a dollar cap.

## Vibe-Trading: larger engineering surface

**Direct:** the pinned inventory contains 30 bundled swarm YAML presets and 90 finance `SKILL.md` files, plus a wrapper skill. These are available templates/instructions, not 30 concurrent trading teams. Dependency layers allow independent work to run concurrently and require completed upstream work before dependent tasks proceed. Failed/incomplete/cancelled states are explicit. The older 29/74 figures in the supplied Gemini text do not describe this pinned inventory.

**Direct:** the function named `walk_forward_analysis` divides an already generated equity curve/trade list into windows. It does not fit, select or rerun a strategy on successive unseen periods. Interpret that function as post-hoc window consistency. This is not a claim that the entire repository lacks out-of-sample tools: a separate factor benchmark supports explicit train/test splits and random controls, and the quant-strategy preset correctly requires a separate out-of-sample run before claiming an overfitting gap. [Window analysis, lines 232–319](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/backtest/validation.py#L232), [preset, lines 110–113](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/swarm/presets/quant_strategy_desk.yaml#L110).

**Direct:** the inspected stock engine shifts signals by one asset-calendar bar, but that cannot detect future-looking calculations inside arbitrary strategy code. Its US defaults include 0.01-share sizing and 5 bp one-way slippage; the base account defaults to $1 million. Those explicit simulation choices require account-size configuration and validation of execution assumptions for our $1,000 reference; they do not demonstrate implementation for that account. [US engine, lines 82–88 and 154–208](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/backtest/engines/global_equity.py#L82), [base alignment, lines 329–365](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/backtest/engines/base.py#L329).

**Direct:** its options-portfolio path generates synthetic prices from underlying bars using Black–Scholes and historical-volatility assumptions. It does not use historical executable option quotes in that path. Defaults include a $1 million account and a contract multiplier of 1; margin checks are modeled. That cannot substitute for our private quote-cache replay or demonstrate listed-contract feasibility at $1,000. [Options engine scope, lines 1–18](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/backtest/engines/options_portfolio.py#L1), [defaults, lines 233–249](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/backtest/engines/options_portfolio.py#L233).

**Direct:** the reviewed broker gate checks a stored mandate, expiry, halt state, account binding, parsed intent and deterministic limits before forwarding. The transport does not automatically retry remote tool calls. These are useful concepts, but source presence is not evidence of reconciled fills or compatibility with Forecast Lab's paper authority. [Gate, lines 134–231](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/live/order_guard.py#L134), [transport, lines 772–797](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/tools/mcp.py#L772).

**Direct / code-path inference:** transport exceptions become error envelopes; this gate records those as rejected orders without consuming the daily count. An exception after submission can instead mean an unknown outcome. Auditing also occurs after forwarding and audit-write failure is non-blocking. Do not adopt that classification as proof an order was never placed. Forecast Lab's required behavior remains durable intent before submission, deterministic IDs and lookup/reconciliation of uncertain outcomes. This is a scoped review of the inspected MCP path, not a claim that every connector or runtime path has the same behavior. [Error envelope, lines 625–659](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/tools/mcp.py#L625), [forward/audit, lines 364–432](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/live/order_guard.py#L364), [audit failure, lines 754–795](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/live/order_guard.py#L754).

**Direct:** its model decision budget persists usage, refuses unfinished decisions and can stop on unaccounted usage. However, its own contract states that token/estimated-dollar limits can overshoot by a response. Dollar prices/caps are optional and supplied by the operator. This is useful measured accounting, not the strict pre-call shared reservation required for a small free-credit budget. [Decision budget, lines 1–48 and 138–201](https://github.com/HKUDS/Vibe-Trading/blob/097b29feab9793e3c302e1a7a4f3c0dac6344904/agent/src/live/runtime/decision_budget.py#L1).

**Direct / inference:** the swarm retry path clears a failed attempt's artifact directory before retry. Archive each failed attempt first if adapting that lifecycle; otherwise it conflicts with our retain-all-trials requirement. ## Corrections to the supplied Gemini summary

1. **“The viral videos are deceptive.”** The accessible captions describe unverified self-reported claims. No wallet, complete ledger or original account record was authenticated. That supports withholding belief in the returns; it does not establish fabrication or prove that either specific video used memecoins/Polymarket. The earlier Instagram leads remain unverified and are not performance evidence for either repository.
2. **“CrewAI forces slow sequential pipelines.”** Incorrect as a framework limitation. CrewAI supports asynchronous tasks, concurrent crews and branching Flows with joins. Internal dependencies still matter; launching an entire crew asynchronously does not automatically parallelize all its tasks. [Official task concurrency](https://docs.crewai.com/en/concepts/tasks#asynchronous-execution), [async crews](https://docs.crewai.com/en/learn/kickoff-async), [Flows](https://docs.crewai.com/en/concepts/flows).
3. **“Use LangGraph or AutoGen to fix it.”** LangGraph supports parallel branches and checkpointed recovery, but those features do not establish better trading decisions. AutoGen's directly inspected current README says archived/no longer maintained and points new users to Microsoft Agent Framework; older indexed maintenance-mode wording is stale. [LangGraph parallel execution](https://docs.langchain.com/oss/python/langgraph/use-graph-api#run-graph-nodes-in-parallel), [persistence](https://docs.langchain.com/oss/python/langgraph/persistence), [AutoGen notice](https://github.com/microsoft/autogen).
4. **“Successful builds use cheap local 70B/DeepSeek models and raw JSON.”** The supplied sources do not establish that performance or cost claim. Hardware, model variant, input length, quality and measured latency matter. JSON improves validation; it does not calibrate an invented 85% confidence score. CrewAI also supports local models, so that choice is independent of framework selection. [CrewAI model support](https://docs.crewai.com/en/concepts/llms), [DeepSeek model variants](https://github.com/deepseek-ai/DeepSeek-R1).
5. **The cited articles are not trading validations.** The [Raghunandan Gupta article](https://raghunitb.medium.com/how-crewai-revolutionized-my-workflow-a-users-journey-into-multi-agent-ai-a0a2a14ffd63) describes URL validation, screenshots and report production. The [Nishant Gupta article](https://medium.com/aigenverse/a-developers-guide-to-multi-agent-frameworks-crewai-autogen-and-langgraph-15531c0c7dfe) exposed only its member-only preview. Its hidden content was not accessed or inferred. Neither accessible source substantiates Gemini's trading-latency or profitability claims.

The valid design insight is to separate evidence gathering and criticism from numerical accounting, sizing and execution. Parallelize independent research when useful; preserve dependencies where one step needs verified output from another. Our daily/weekly research does not need to imitate a subsecond memecoin trading system.

## Concrete next experiment

Continue the existing bounded process-pilot proposal: identical frozen tasks for a deterministic control, one research agent and a small proposer/data-reviewer/critic team. Use our existing assistant workflow first; no third-party service is required to begin reviewing data and code. Record source/time claims, confirmed defects, complete trial records, wall time and usage. Promote a framework only if measured benefits justify its integration and operating cost.

The first financial experiment remains separate: freeze rules, universe, timing, sizing, costs and trial count before observing outcomes; pass validated decisions to deterministic funded-account accounting; retain all annual returns and failures. Current historical inputs and model knowledge do not constitute an untouched test. Live news-driven model policies require prospective timestamped observations and measured operating costs.

At $1,000, a 10–20% annual objective represents $100–$200. A hypothetical $10/month operating bill consumes $120/year before trading frictions. That arithmetic is not a vendor quote. Measure one-time research costs separately from ongoing operation. Existing API provider/balance/expiry/caps remain unknown and the proposed external-model allowance remains zero.

Private Databento transfer and frozen options reproduction remain outstanding. Neither framework supplies our missing licensed options cache, and this review has not validated funded-account options accounting, including integer contracts, collateral, assignment and expiry, for our $1,000 reference. No new backtest performance or broker fill is reported by this review.
